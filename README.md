# CAT HELP：猫宅调查档案

一款无需后端的多章节非线性文字检索推理游戏。第一章调查红色铃铛球的失踪路线，第二章厘清五份冻干与错误身份归因，第三章《封闭阳台的陌生爪印》复原被擦乱的现场痕迹方向。

## 运行

需要 Node.js 18 或更高版本，无第三方依赖。

```bash
npm run dev
```

浏览器访问 `http://localhost:4173`。每章调查进度独立保存在浏览器本地；设置中可重开当前章节或清除全部章节进度。

首次进入每项功能时会显示对应操作教学。顶部“教学”可查看学习进度、重看聚焦讲解、关闭自动教学或重置教学进度；这些设置同样保存在浏览器本地。

## 验证

```bash
npm test
npm run check
```

## 目录

- `src/content/cases/`：各章节的记录、角色、地点、关键词与谜题答案
- `src/content/case-catalog.js`：章节顺序与解锁目录
- `src/engine/`：案件绑定搜索引擎、数据驱动推理与分章存档逻辑
- `src/ui/`：界面样式
- `test/`：引擎与内容可达性测试
- `scripts/`：本地静态服务器和内容检查
- `docs/`：游戏设计、真实时间线与线索依赖文档
