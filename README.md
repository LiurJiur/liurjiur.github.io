# CAT HELP：玩具球失踪事件

一款无需后端的非线性文字检索推理游戏。玩家通过家庭群聊、猫猫证词与智能设备日志，还原红色铃铛球的失踪路线。

## 运行

需要 Node.js 18 或更高版本，无第三方依赖。

```bash
npm run dev
```

浏览器访问 `http://localhost:4173`。游戏进度保存在浏览器本地，可在设置中清除并重新开始。

首次进入每项功能时会显示对应操作教学。顶部“教学”可查看学习进度、重看聚焦讲解、关闭自动教学或重置教学进度；这些设置同样保存在浏览器本地。

## 验证

```bash
npm test
npm run check
```

## 目录

- `src/content/`：角色、地点、记录、关键词与谜题答案
- `src/engine/`：搜索、解锁、事实判定与存档逻辑
- `src/ui/`：界面样式
- `test/`：引擎与内容可达性测试
- `scripts/`：本地静态服务器和内容检查
- `docs/`：游戏设计、真实时间线与线索依赖文档
