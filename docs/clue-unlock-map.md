# 《CAT HELP：玩具球失踪事件》线索与解锁关系表

## 1. 文档用途

本文档定义玩家能看到的调查内容、解锁条件、关键词传播路径和最终答案证据。它同时用于：

- 剧情记录编写
- 内容数据录入
- 搜索与解锁引擎实现
- 自动化内容完整性测试
- 试玩卡点排查

案件事实以[案件真实时间线](./true-timeline.md)为准，产品范围以[游戏设计概要](./game-design-overview.md)为准。

## 2. 解锁规则

### 2.1 概念状态

每个可搜索概念有四种状态：

- `unknown`：玩家尚未在任何已读内容中见过，不参与自动补全。
- `discovered`：玩家已经在已读内容中见过，会出现在笔记和自动补全中。
- `collected`：玩家已点击收集或主动输入搜索；记录内首次点击只收集，后续点击才检索。
- `confirmed`：已有足够证据，被写入时间线或事实笔记。

玩家仍可输入尚未发现的有效词，但关键流程不得要求这样做。

### 2.2 解锁条件

- `START`：开始调查时直接可见。
- `READ:<ID>`：阅读指定记录后解锁。
- `SEARCH:<概念>`：搜索已经发现的概念后解锁。
- `ALL:<条件...>`：满足全部条件后解锁。
- `ANY:<条件...>`：满足任一条件后解锁。
- `CONFIRM:<事实>`：玩家通过证据或阶段推理确认事实后解锁。

同一记录可以配置多条可选路径，防止玩家因调查顺序不同而卡死。

## 8. 最终推理结构

### 8.1 事件排序

玩家需要按顺序排列：

1. 小酒把球拍入厨房。
2. 铁胆进入厨房偷吃并离开。
3. 小流儿把球放入蓝箱。
4. 小扫撞击蓝箱，球落入后部收纳篮。
5. 小扫返回洗衣阳台充电座。

### 8.2 选择题

| 问题 | 正确选项 | 常见错误选项及反馈方向 |
| --- | --- | --- |
| 最后正常玩球的是谁？ | 小酒 | 选铁胆：查看 20:07 的目击记录。 |
| 小酒之后，谁第一次主动拿走了球？ | 小流儿 | 选铁胆：他在 20:17 仍看见球停在门边。 |
| 哪两只猫为掩盖自己的秘密，提供了与客观记录冲突的证词？ | 铁胆、小流儿 | 漏选铁胆：项圈记录反驳“一直睡觉”。漏选小流儿：蓝箱痕迹反驳“没见过球”。小酒只是不完整说明；糖心所说的“没碰球”有二楼定位支持。 |
| 什么最终带走了球？ | 小扫 | 选小流儿：需要解释 20:33 的第二次铃声。 |
| 球在哪里？ | 洗衣阳台的小扫后篮 | 选蓝箱：箱内只有压痕，之后仍有铃声与机器人返航记录。 |

### 8.3 证据选择

玩家为“球被小扫带走”选择证据时，以下组合均可判定为充分：

- `REC-07` + `REC-09` + `REC-11` + `FILE-07`
- `FILE-05` + `REC-09` + `REC-10` + `FILE-07` + `REC-11`
- 已确认的 `SUM-03` + `FILE-07` + `REC-11`
