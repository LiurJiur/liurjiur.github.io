# 《CAT HELP：玩具球失踪事件》案件真实时间线

## 1. 文档用途

本文档记录作者视角下唯一真实、完整的事件经过，是编写证词、设备日志、谜题答案和结局文本的事实基准。

面向玩家的内容可以省略、误解或歪曲这里的事实，但不得与最终真相产生无法解释的冲突。修改本时间线后，必须同步检查[线索与解锁关系表](./clue-unlock-map.md)。

## 2. 案件摘要

小酒在客厅玩红色铃铛球时将球拍进厨房，球撞到零食罐并使两条小鱼干掉落。铁胆发现后偷吃了鱼干，并为了掩饰自己的行为将罐子推回原位，却没有处理滚到门边的球。

小流儿随后捡到球，暂时放进自己的蓝色秘密收藏箱，并把纸箱留在走廊。定时启动的扫地机器人小扫撞到纸箱，球从未完全合拢的箱盖中掉出，落进小扫后部的拖布收纳篮。小扫完成清扫后回到洗衣阳台充电，最终把球带到了那里。

案发前，糖心追逐逗猫棒时撞歪了厨房门，间接让球能从客厅滚进厨房；她没有碰过球。松花整晚大多在走廊暖气垫上睡觉，只在翻身时短暂看见小扫经过。两人提供的是补充证词，不是失踪链条中的直接移动者。

没有任何角色有意长期偷走或破坏玩具球。

## 3. 关键对象

### 3.1 红色铃铛球

- 所有者：小酒
- 外观：红色毛毡表面，内部有一枚小铃铛
- 特征：滚动时会发出清脆铃声；表面容易粘猫毛
- 最终状态：完好，除小酒留下的黑色猫毛外，还沾有一根小流儿的白色长毛和少量灰尘
- 最终位置：洗衣阳台，小扫后部的灰色拖布收纳篮内

### 3.2 蓝色纸箱

- 来源：桂花下午拆开的猫砂快递箱
- 外观：蓝色印花，箱盖无法完全闭合
- 用途：小流儿的临时“秘密宝物馆”
- 事发前内容：瓶盖、羽毛、绿色丝带、软木塞
- 事发后变化：短暂放入红色铃铛球；被小扫撞歪；绿色丝带掉在走廊

### 3.3 扫地机器人“小扫”

- 20:30 按计划自动启动
- 具有前向碰撞传感器和简单障碍物分类
- 后部安装开放式拖布收纳篮
- 低电量时返回洗衣阳台充电座
- 无法识别落入收纳篮的小型物体

- 知道自己把球打进了厨房。

- 知道自己把球放进蓝箱并把箱子留在走廊。

### 糖心

- 知道自己在 19:46 撞歪了厨房门，也知道当时球还没有失踪。

### 松花

## 9. 误导支线

### 9.1 铁胆偷吃

铁胆的谎言和厨房银灰色毛尖会让他成为早期嫌疑对象。但定位记录和小流儿后续行动可以证明，他最后看到球时，球仍在厨房门边。他隐瞒的是偷吃，不是偷球。

### 9.2 小流儿的秘密收藏

小流儿确实未经允许拿走了球，属于失踪链条的重要一环，但她并不知道最终位置。她的蓝箱是中转点，不是终点。

### 9.3 胡椒爷爷的“蓝色影子”

这不是未知角色，而是他将主体颜色与物体颜色记反。其他资料确认当时经过走廊的是白猫小流儿，携带蓝色纸箱。

### 9.4 糖心撞门与松花睡觉

糖心留下的门磁记录和金色短毛解释了厨房门为什么半开，19:49 起的二楼项圈定位则排除了她后来接触球的可能。松花的睡觉状态有暖垫数据支持；他短暂醒来看到小扫，反而为设备日志提供了一条角色证词旁证。两条支线用于扩充嫌疑面，同时训练玩家区分“与条件有关”和“直接移动物品”。

## 11. 结局演出

玩家提交正确推理后，桂花让全家前往洗衣阳台检查小扫。小酒从灰色拖布收纳篮里找回红球；球一响，小扫立即重新播报“检测到可移动障碍物”，形成结尾笑点。

铁胆主动承认偷吃，小流儿公开自己的“宝物馆”，小酒也承认撞到零食罐。糖心别扭地把厨房门推回原位，松花则抱着暖垫在阳台门口等大家。桂花没有处罚任何猫，而是制定三条新家规：

1. 玩球时关好厨房门。
2. 收藏别人的物品前先留言。
3. 小扫回充后检查拖布篮。

结算文本可根据玩家是否揭开铁胆偷吃、小流儿收藏、糖心撞门和松花短暂醒来等可选信息略有变化，但球被找回的主结局保持一致。
