# CAT HELP 角色设定基准

## 1. 文档用途

本文档保存跨章节稳定的角色身份、外貌和性格。案件中的秘密、证词和临时状态仍由各章定义；章节内容不得随意改变这里的基础设定。

## 2. 核心角色

| 角色 | 稳定外貌 | 稳定性格与能力 | 内容约束 |
| --- | --- | --- | --- |
| 小流儿 | 白猫，蓝黄异瞳，尾巴修长 | 安静、脑子聪明、擅长观察与整理，喜欢收藏 | 她的聪明应体现在发现证据关系和提出可验证问题，不能只靠一句“她很聪明”直接公布答案 |
| 小酒儿 | 黑猫，黄眼睛，一身肌肉 | 精力充沛、好动、玩心重、说话直接 | 体力和爆发力可以成为行动线索；不能把“肌肉”简单等同于粗鲁或迟钝。正文口语可称“小酒”，角色正式名统一为“小酒儿” |

| 角色 | 稳定外貌 | 稳定性格与习惯 | 内容约束 |

## 5. 数据建议

跨章共享角色只存稳定信息，例如：

```js
{
  id: "cat-xiaojiu",
  name: "小酒儿",
  aliases: ["小酒"],
  coat: "黑色短毛",
  eyes: ["黄色", "黄色"],
  traits: ["精力充沛", "肌肉发达", "玩心重"]
}
```

章节内档案再补充该章的表面嫌疑、临时动机、已知位置和可解锁秘密。角色 ID 跨章稳定，显示名称和别名通过共享注册表解析。
