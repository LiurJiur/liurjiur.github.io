# 第二章《午夜加餐疑云》游戏设计

## 1. 章节定位

- 案件编号：`case-002`
- 章节名称：《午夜加餐疑云》
- 推荐时长：35～45 分钟
- 发生地点：邻居 66 家“云朵宅”
- 核心角色：小流儿、小酒
- 重点角色：糖心、松花、66
- 参与角色：铁胆
- 不参与本章剧情：桂花、胡椒爷爷

本章延续温暖、轻悬疑、没有真正反派的基调，但不再重复“寻找失物”。玩家需要调查一次异常的午夜加餐：智能零食机在非开放时段连续发出了五份月亮鱼冻干，审计摘要却把会话最终归在了小流儿名下，而现场只找到四只空食杯，第五份去向不明。

## 2. 一句话概念

在 66 家留宿的第二天早晨，CAT HELP 将半夜发出五份冻干的会话最终归在小流儿名下；小流儿坚称自己当时仍在睡觉，现场记录却牵出了六只猫在午夜前后的不同动作。

## 3. 本章目标

相较第一章，本章重点强化：

1. **身份不等于行为**：设备记录中的身份来自可移动访客标签，不能直接等同于操作者。
2. **连续动作拆解**：五份冻干不是一次行为造成，而是“预设夜宵暗号 + 意外连触”的结果。
3. **群体责任**：没有单一偷吃者，不同角色分别参与了计划、误触、分配、食用和证物保留。
4. **角色成长**：小流儿从第一章的秘密收藏者，变成会主动保留证物的调查搭档。
5. **图案密码题**：玩家需要解开 66 留下的四位图案密码，才能查看“六六专属夜宵”的设置记录。
5. **新角色辨识度**：66 在自己家里爱发号施令，遇到雷声又会立刻拉小酒壮胆，体现“窝里横”。

## 4. 角色分工

| 角色 | 本章状态 | 表面嫌疑 | 实际行为与成长 |
| --- | --- | --- | --- |
| 小流儿 | 核心调查搭档 | 零食机记录最后显示是她操作了 00:22 的出粮 | 事发时仍在睡眠舱；醒来后保留第五份冻干作为证物，但为了保护朋友暂时没有公开 |
| 小酒 | 核心涉事者 | 强调自己只在第一份出粮后靠近面板 | 扑向闪烁的面板，碰出四组连续三下，造成四次额外触发 |
| 糖心 | 现场组织者 | 否认碰过机器 | 冲向零食机时撞倒访客标签架，造成小流儿身份被误读；随后强行把五份冻干排好分配 |
| 松花 | 睡眼惺忪的见证者 | 说自己把午夜加餐当成了早餐 | 确实半睡半醒吃掉一份；暖垫记录和他的零碎回忆能还原现场分配情况 |
| 66 | 新角色、计划发起者 | 在自己家最熟悉设备，却一口咬定是系统故障 | 提前设置“夜宵暗号”，雷响后拉小酒陪同，亲手触发第一份；事后因怕丢面子而否认 |
| 铁胆 | 食物线索证人 | 贪吃经历使他很容易被当作计划者 | 闻到香味后才到场并吃掉一份；这次从调查开始就承认，且能证明糖心只分配、没有食用 |

### 4.1 66 的角色表达

- 毛色：布偶猫，重点表现浅色长毛、深色耳面和蓬松尾巴。
- 身份：住在隔壁、与小酒等猫玩得很好的邻居弟弟。
- 性格：在自己家里很有主人架势，喜欢规定游戏规则、分配座位和展示设备；离开熟悉区域或遇到突发声响时明显胆小。
- 说话特点：常说“在我家听我的”，心虚时会强调“我只是演示一下”。
- 动机：想证明自己能绕过零食机的夜间限制，也想招待朋友，不是为了独吞。

## 5. 案件谜面

清晨 07:10，云朵宅 CAT HELP 自动生成异常报告：

- 零食机在 00:22 的锁定时段连续发出五份“月亮鱼冻干”。
- 零食机记录最后显示的名字是“小流儿”；明细仍保留最初认出的主人标签和之后的名字变化时间。
- 客厅与暖垫附近共找到四只空食杯。
- 第五只食杯及其中的冻干去向不明。
- 小流儿表示自己没有操作设备；她睡前把访客牌挂在标签架上，夜里也没有佩戴或使用它。
- 66、小酒、糖心、松花和铁胆都声称自己不是发起者；铁胆同时主动承认吃过一份。

玩家最终需要回答：

1. 谁预先设置并启动了午夜加餐？
2. 为什么机器最终发出了五份，而不是一份？
3. 为什么零食机记录最后把操作算在小流儿名下？
4. 哪四只猫吃掉了现场的四份冻干？
5. 没有被吃掉的第五份在哪里？
6. 将关键事件按正确顺序排列。

## 6. 真相概述

66 在 21:35 趁展示设备时进入演示状态，并设置“连续轻拍三下发一份”的夜宵暗号。00:18，一声雷把他吓醒，他嘴上说要巡查自己的家，实际叫醒小酒陪他去客厅。00:22，66 用三次规律轻拍触发了第一份冻干。

出粮灯闪烁时，小酒把光点当成玩具扑向面板，在这轮操作记录尚未结束的几秒内碰出了四组连续三下；每组都对上夜宵暗号，于是机器又发出四份。糖心听见机器响动后冲出房间，撞歪了旁边的访客标签架。小流儿挂在架上的访客牌滑到识别区，设备把记录最后显示的名字改成小流儿，但没有改变此前认出的 66 主人标签和五次出粮的明细时间。

糖心发现已经出了五份，便强行把冻干排成一列，要求大家不许争抢。66 和小酒各吃一份；铁胆循着香味赶到，接过糖心分给他的第三份，并明确看见糖心没有吃。松花随后半睡半醒地离开暖垫，把午夜当作早餐，也吃了一份。小流儿在 00:25:40 被持续的访客牌离架提醒吵醒，看到现场后将唯一未拆的第五份装进“星星证物袋”，既防止继续偷吃，也保留了机器批次标签。她担心单独拿出证物袋会被误解为藏起自己领取的冻干，等客观记录证明她在出粮结束后才到场，才主动出示证物袋。

因此，零食机记录中的“小流儿”只是最后识别到的名字，不是最初被认出的主人或实际操作者；五份冻干来自 66 的一次计划触发和小酒的四次意外触发。

## 7. 核心事实

| ID | 事实 | 最少证据组合 |
| --- | --- | --- |
| `FACT-01` | 66 设置并启动了午夜加餐 | 夜宵暗号设置记录 + 面板首次轻拍记录 |
| `FACT-02` | 小酒的扑击造成四份额外出粮 | 面板触摸序列 + 面板毛发与爪垫痕迹 + 低位动作记录 |
| `FACT-03` | 糖心撞落小流儿的访客牌，导致记录认错了猫 | 标签架碰撞痕迹 + 访客牌识别明细 + 小流儿睡眠舱记录 |
| `FACT-04` | 66、小酒、铁胆、松花各吃掉一份，糖心只负责分配 | 空食杯痕迹 + 铁胆健康项圈 + 暖垫记录 + 铁胆现场回忆 |
| `FACT-05` | 小流儿保存了未拆封的第五份 | 睡眠舱记录 + 访客牌移动记录 + 星星证物袋 + 小流儿完整说明 |

## 8. 事件卡

最终推理包含六张排序卡：

1. `EVT-01`：66 被雷声惊醒，叫小酒陪他去客厅。
2. `EVT-02`：66 轻拍面板三下，触发第一份冻干。
3. `EVT-03`：小酒扑击闪灯，碰出四组连续三下，额外触发四份。
4. `EVT-04`：糖心撞歪标签架，小流儿访客牌进入识别区。
5. `EVT-05`：糖心分配冻干，铁胆和松花先后加入。
6. `EVT-06`：小流儿醒来，将未拆的第五份保存为证物。

## 9. 玩法增量

本章只增加一个主要推理概念：**设备身份归因可能被外部标签污染**。界面层可以复用第一章的搜索、记录、时间线、提示和排序交互。

调查 66 的夜宵暗号时，会先遇到一个四位图案密码锁。机器旁贴着 66 写给自己的便利贴，用“凑在一起是 12”“翻一倍再加 1”“多 2”“躲在两个数字中间”等童趣说法，描述爪印、月亮、小鱼和铃铛的关系。玩家求出四个数字后，再按“小鱼、月亮、铃铛、爪印”的涂画顺序得到 `5763`。密码可在记录内提交，也可直接输入检索框；正确后解锁设置记录。谜题只阻挡一条局部证据链，全部规则和组合顺序都在同一题面给出。

最终推理需要比第一章更数据化：

- 单选：计划发起者。
- 单选：额外触发者。
- 单选：标签架碰撞者。
- 多选：实际食用者。
- 单选：第五份位置。
- 排序：六张事件卡。

这意味着案件数据不能继续依赖当前固定的 `lastPlayer`、`firstTaker`、`liars`、`carrier`、`location` 字段，应改为由案件声明题目类型、选项与校验答案。

## 10. 章节衔接

- 第一章结案后解锁第二章，但两章进度互相独立。
- 小流儿使用“星星证物袋”，自然表现她从收藏秘密到保留证据的成长。
- 小酒仍然会因追逐移动光点造成意外，但这次主动承认证词应比第一章更快，体现成长而非重复。
- 糖心从被动排除嫌疑的支线角色升级为现场秩序的建立者。
- 松花的睡眠习惯不只用于不在场证明，而是成为还原食物数量和现场顺序的关键。
- 铁胆不再重复第一章“偷吃后否认”的行为；他主动承认吃过一份，并用自己的食物辨识和项圈记录帮助核算现场。
- 66 可以在后续章节继续作为“邻居设备与外部地图”的入口，但不需要立刻发展跨章阴谋。

## 11. 完成标准

- 玩家无需第一章细节也能独立推出全部答案。
- 每个必要概念均能从初始记录或已读正文继续发现。
- “日志写着小流儿”不能成为无证据可反驳的文字陷阱，至少提供睡眠舱与标签移动两类客观证据。
- 五份冻干的数量必须逐份可解释。
- 66、糖心、松花和铁胆都至少拥有一条主线必要证据，不能退回可跳过支线。
- 结局明确所有猫都安全，且没有把普通贪吃行为塑造成严重道德问题。
