# 第三章《封闭阳台的陌生爪印》线索与解锁关系表

## 1. 文档用途

本文定义第三章的调查记录、概念传播路径、事实生成条件和最终答案证据。事实以[第三章真实时间线](./chapter-03-true-timeline.md)为准，人物外貌和性格以[角色设定基准](./character-bible.md)为准。

### 3.7 图形题题面规格

#### `LOCK-01` 被擦乱的足迹卡

初始排列为 `B-D-C-A`，题面卡片内容如下：

| 卡片 | 文字等价描述 | 左边缘 | 右边缘 |
| --- | --- | --- | --- |
| A | 泥迹纹理 3；完整右前大爪后接左后小爪 | 半枚右前爪，与 C 相接 | 一截断叶 |
| B | 泥迹纹理 1；补全最后一枚右前大爪，足迹停在湿巾盒前 | 半枚右前爪，与 D 相接 | 湿巾盒边线 |
| C | 泥迹纹理 4；从翻倒猫草盆开始，左前大爪后接右后小爪 | 猫草盆碎土 | 半枚右前爪 |
| D | 泥迹纹理 2；左前大爪后接右后小爪 | 断叶，与 A 相接 | 半枚右前爪 |

正确顺序为 `C-A-D-B`。三级提示依次为“泥越走越浅”“检查卡片边缘的半枚脚印与断叶”“顺序是 C-A-D-B”。

#### `LOCK-02` 安全锁方向密码

题面同时显示九宫格和文字方向：

```text
7 8 9       受力顺序：右 → 右上 → 上 → 左
4 5 6
1 2 3
```

以 `5` 为中心读取方向，答案为 `6984`。箭头采用锁体局部坐标，解锁前不显示锁体在外门上的安装朝向；安装朝向只在 `REC-05` 中给出。三级提示依次为“把 5 当作锁芯”“右边对应 6，右上对应 9”“完整密码是 6984”。

#### `LOCK-03` 香香去湿巾盒的路线

图例：`P` 猫草盆、`G` 玻璃内门、`T` 餐桌外侧、`M` 饭垫、`W` 湿巾盒。四张候选路线均需画在同一底图比例上：

| 路线 | 经过顺序 | 排除或保留原因 |
| --- | --- | --- |
| A | `P → G → M → W` | 会踩到饭垫，与饭垫无新增压力冲突 |
| B | `P → G → T → G → W` | 玻璃内门会触发两次，与单次门磁冲突 |
| C | `P → G → T → W` | 同时符合单次门磁、第三组餐桌外侧压力和湿巾盒方向 |
| D | `P → T → G → W` | 在通过玻璃内门前就到达室内餐桌外侧，空间关系不成立 |

正确答案为路线 C。三级提示依次为“先排除饭垫被踩的路线”“内门只能经过一次”“选择 P → G → T → W”。

## 5. 防卡死要求

- 五名角色都必须在 `CHAT-01` 中出现，且不得通过其他章节角色提供必要线索。
- `大爪印` 同时引出小流儿的疑问和足迹模型说明。
- `猫草盆` 同时由警报、地图和小流儿初始疑问引出。
- `白色纤维` 直接出现在警报中，玩家无需先猜到臭臭的衬衫。
- `吃饭要摸摸` 必须出现在臭臭可读的初始角色档案中，能够自然导向饭垫记录。
- `过敏` 和 `大前爪` 必须由香香初始档案或初始证词给出。
- `吸水垫` 同时由地图和警报快照中的擦拭水痕引出。
- 判断“没有陌生猫”至少依赖门禁和泥土两种不同来源，不能只凭封闭环境直接排除。
- `LOCK-01` 必须提供泥迹纹理编号和脚印轮廓，不能只依赖深浅颜色。
- `LOCK-02` 必须在题面直接显示九宫格与方向文字，不要求玩家知道键盘方位约定。
- `LOCK-03` 必须同时支持点击路线卡和键盘单选；`FILE-09` 还要保留完整文本证据的解锁路径。
